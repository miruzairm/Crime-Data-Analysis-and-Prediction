The Project Aims at analysing Crime prediction of Indian states, it uses machine learning techniques to predict crime trends. The Crime Prediction is done on various types of crimes, such as Murder, Kidnapping, Rape, Theft, & Cheating. The Data is Collected from the NCRB website of the Govt of India. Once the data is collected, it is analysed using machine learning algorithms to identify patterns and trends in the data that can help predict future crime rates.

The project also includes a simple line graph analysis of the crime data for each state, Spatial Data Analysis is also done with hot spot mapping of Indian Map based on Total Crimes in Each state in the year 2021. Analysis of Total Crimes for Years 2000-2021 of the country is also shown in Total Crime Analysis. By analysing crime data and predicting trends, this project can help law enforcement agencies and policymakers make informed decisions about crime prevention and public safety.

*The Prediction is only available for years 2022-2025
*All Data may not be accurate

The Spatial Data Analysis map is created using iipmaps.com
Source of data: ncrb.gov.in
